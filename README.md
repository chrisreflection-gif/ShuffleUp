# Shuffle Up

A random Commander deck picker for [playgroup.gg](https://playgroup.gg) players.

Paste a playgroup.gg profile link to load that player's active decks, bench any you don't want in the draw, then shuffle. Add several players for game night and everyone gets their own pick. Your players, benched decks and last picks are remembered in your browser.

Live site: https://chrisreflection-gif.github.io/deck-randomiser/

Deck data comes from the [playgroup.gg public API](https://playgroup.gg/api-docs/index.html). Only public, non-archived decks appear. Card art via Scryfall.
